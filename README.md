# Spatial Morphology

### Generative Architectural Design System

Spatial Morphology is a computational design tool developed using Rhino 8, Grasshopper, and Python 3.

It explores architectural massing through spatial configuration, adjacency relationships, generative algorithms, and evolutionary optimization.

## Main Components

1. **Program Definition** – Defines spatial programs, areas, zoning, and adjacency.
2. **Spatial & Morphology** – Generates spatial configurations based on design constraints.
3. **Evolutionary Engine** – Explores alternative configurations through evolutionary algorithms.
4. **Performance Evaluator** – Evaluates spatial and morphological performance.
5. **Geometry Generator** – Translates selected configurations into 3D architectural massing.

## Technology

- Rhino 8
- Grasshopper
- Python 3
- Evolutionary Algorithms
- Space Syntax Principles
